# My Cartoon Network

Static video site ready for GitHub Pages.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `script.js`, `videos.json`, and `.nojekyll`.
3. Open the repository's **Settings**.
4. Open **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and the `/ (root)` folder.
7. Click **Save** and wait for GitHub to provide the public site link.

The site loads `videos.json` using a relative path and uses the public video URLs from the JSON file. After publishing, visitors can open it directly from the public site link.
